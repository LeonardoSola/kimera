Política de Privacidade

Kimera Uploader · atualizado em 14/11/2026

1. Quais dados

Somente os dados necessários para publicar vídeos na conta do próprio criador: o token de acesso concedido pela plataforma (YouTube, Instagram ou TikTok) e informações básicas do perfil (nome de exibição/ID) usadas para confirmar qual conta está conectada.

2. Onde ficam

Os tokens ficam armazenados apenas no computador do criador. Nenhum dado é enviado a servidores do Kimera — não existe servidor próprio.

3. Compartilhamento

Nenhum dado é vendido, compartilhado ou usado para publicidade. Os dados só são enviados às próprias plataformas, no momento da publicação.

4. Dados de terceiros

A ferramenta não coleta dados de espectadores nem de outras contas.

5. Serviços de API do YouTube

O Kimera Uploader usa os Serviços de API do YouTube (YouTube API Services). Com a autorização do usuário (Google OAuth), ele acessa apenas: o envio de vídeos para o próprio canal (videos.insert), a consulta do status desses vídeos (videos.list) e o nome do canal conectado (channels.list). Esses dados são usados só para publicar e confirmar a publicação; não são armazenados, exceto o token de acesso no computador do usuário.

Os dados também são tratados pelo Google conforme a Política de Privacidade do Google. O uso do YouTube segue os Termos de Serviço do YouTube.

6. Remoção e revogação

O acesso pode ser revogado a qualquer momento: no Google, em Conta do Google → Segurança → Apps com acesso à conta; no Instagram e no TikTok, em Apps e sites / Segurança. Ao revogar, ou ao apagar o arquivo de token local, os dados deixam de existir imediatamente — não há cópias em servidores. Dados obtidos da API do YouTube nunca são guardados por mais de 30 dias.

7. Contato

Pelo canal youtube.com/@eu.kimera.

English summary

Kimera Uploader uses the YouTube API Services. With the user's OAuth consent it only uploads videos to the user's own channel and reads their status and the channel name. Only the OAuth token is stored, locally on the user's computer; nothing is sent to any Kimera server (there is none) or shared with third parties. Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time via the Google security settings page.
