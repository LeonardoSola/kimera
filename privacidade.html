Política de Privacidade

Kimera Uploader · atualizado em 14/11/2026

1. Quais dados

Somente os dados necessários para publicar vídeos na conta do próprio criador: o token de acesso concedido pela plataforma (YouTube, Instagram ou TikTok) e informações básicas do perfil (nome de exibição/ID) usadas para confirmar qual conta está conectada.

2. Onde ficam

Os tokens ficam armazenados apenas no computador do criador. Nenhum dado é enviado a servidores do Kimera — não existe servidor próprio.

3. Compartilhamento

Nenhum dado é vendido, compartilhado ou usado para publicidade. Os dados só são enviados às próprias plataformas, no momento da publicação.

4. Dados de terceiros

A ferramenta não coleta dados de espectadores nem de outras contas.

5. Remoção

O acesso pode ser revogado a qualquer momento nas configurações de cada plataforma; os tokens locais são apagados junto.
